# Smart URL Shortener with Analytics

A URL shortening REST API built using Python, FastAPI, SQLAlchemy, and SQLite.

## Features

- Generate short links from long URLs
- Support custom aliases
- Redirect users to original URLs
- Track link clicks
- Retrieve URL analytics
- Validate URLs and prevent duplicate aliases
- Automated API tests

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pytest
